Leonida 55 — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words with numbered steps and dated sources, a five-stage roadmap to the platinum, the one confirmed missable trophy flagged, and a checklist that saves progress in the browser with export, import, kind and grade filters, and a spoiler setting. Static files only — no build step, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. The guide works with the network off.
